# Demonstration scenarios

## Scenario A — business-rule change

Input a source/requirement change to the strategic Opportunity threshold. Show contract/graph ingestion, affected Flow/Apex/fields/API/tests, risk, selected validations, live policy evidence and a deterministic recommendation. Policy values come from the Salesforce app contract and source, never hardcoded platform logic.

## Scenario B — permission change

Analyze a permission-set change. Show affected objects/fields/personas, positive and negative authorization obligations, transport-versus-business-authority separation and prevention of administrator-as-VP approval.

## Scenario C — UI presentation change

Analyze a workbench presentation change, invalidate one recorded locator, capture the current DOM, rank candidates using metadata and accessibility evidence, heal only when unique and show before/after Playwright evidence.

## Scenario D — governed degradation

Use a stale graph or unavailable model/Salesforce dependency. Show explicit `INCOMPLETE`/degraded output, preserved deterministic findings, no fabricated claims and a governance scorecard identifying the missing gate.

## Viewer narrative

The dashboard should make five ideas visually obvious: specialized agents cooperate; graph and semantic retrieval provide evidence; the platform selects less but sufficient testing; UI automation adapts safely; and governance controls can block the agent itself.
